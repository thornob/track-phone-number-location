# 🌐 Track Phone Number Location

## 📝 Description
This project allows you to **track the location and carrier** of phone numbers from multiple countries using Python.  
It validates phone numbers, detects their location, and identifies the carrier/network provider.

---

## ✨ Features
- Supports **multiple phone numbers** at once 📱  
- Detects **location** of each number 🌍  
- Detects **carrier/network provider** 📶  
- Works with **international numbers** with country codes 🌐  
- Easy to use and extendable 💻
